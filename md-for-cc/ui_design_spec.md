# 就业指导系统 UI 设计规范
> 技术栈：Vue3 + Element Plus  
> 供 Claude Code 直接使用

---

## 一、整体布局

所有角色登录后统一采用「左侧边栏 + 右侧内容区」布局。

```
┌──────────────┬──────────────────────────────────┐
│              │  顶部栏（系统名 + 用户名 + 退出）  │
│   侧边栏     ├──────────────────────────────────┤
│ 默认 250px   │                                  │
│ 折叠 80px    │         页面内容区                │
│ 可拖拽调整   │                                  │
└──────────────┴──────────────────────────────────┘
```

**配色方案**（以下均从实际模板中提取，页面开发需严格遵守）

| 位置 | 颜色值 | 说明 |
|------|--------|------|
| 侧边栏背景 | `#4f6395` | 中蓝灰，模板实际色 |
| 侧边栏选中高亮背景 | `rgba(255,255,255,0.15)` | 半透明白 |
| 菜单文字 | `#ffffff` | 白色 |
| 菜单激活文字/图标 | `#ffd04b` | 金黄色 |
| 菜单未激活图标 | `rgba(255,255,255,0.6)` | 半透明白 |
| Logo 区底部分割线 | `rgba(255,255,255,0.1)` | 极淡白线 |
| 顶部栏背景 | `#ffffff` | 纯白，底部 `box-shadow: 0 1px 4px rgba(0,0,0,0.1)` |
| 内容区背景 | `#f0f2f5` | 浅灰，所有页面主背景 |
| 卡片/表格背景 | `#ffffff` | 纯白，圆角 `8px` |
| 主色按钮 | Element Plus 默认 `#409EFF` | 操作按钮、链接 |
| 危险色 | `#F56C6C` | 删除、拒绝类操作 |
| 警告色 | `#E6A23C` | 待审核、待处理状态 |
| 成功色 | `#67C23A` | 已通过、已就业状态 |

**侧边栏尺寸规范**
- 默认展开宽度：`250px`
- 折叠宽度：`80px`（只显示图标）
- 可拖拽范围：`60px ~ 500px`
- 折叠触发阈值：拖拽宽度 `< 100px` 时自动折叠
- Logo 区高度：`80px`，含底部分割线

## 三、各页面详细设计

### 3.1 登录页（所有角色共用）

**布局**：居中卡片，宽 `420px`

**内容**：
- 顶部：系统 Logo + 「就业指导系统」标题
- 用户名输入框（placeholder: 请输入用户名）
- 密码输入框（password 类型）
- 角色选择：`el-radio-group`，选项：学生 / 企业 / 辅导员 / 管理员
- 登录按钮（宽 100%，主色）
- 底部：「没有账号？立即注册」链接

**交互**：登录成功后根据角色跳转到对应首页。

---

### 3.2 管理员页面

#### 3.2.1 首页 Dashboard

**4 个统计卡片（一行）**：
| 卡片 | 数据来源 |
|------|---------|
| 总学生数 | student 表 count |
| 总企业数 | company 表 count |
| 今日新增岗位 | job 表按日期 |
| 待审核企业 | company 表 status=待审核 |

**图表区（两列）**：
- 左：折线图——近7天新增学生数
- 右：饼图——学生就业状态分布（已就业 / 求职中 / 未开始）

**底部表格**：最近注册企业列表，字段：企业名称 / 行业 / 注册时间 / 状态 / 操作（审核）

---

#### 3.2.2 学生管理

**搜索栏**：姓名、学号、院系、专业（`el-input` + `el-select`）+ 搜索按钮 + 重置按钮

**操作栏**：新增按钮（右侧）

**表格字段**：学号 / 姓名 / 院系 / 专业 / 就业意向 / 所属辅导员 / 注册时间 / 操作（查看 / 编辑 / 删除）

**新增/编辑弹窗**（`el-dialog`，宽 600px）：
- 学号、姓名、密码、院系、专业、联系方式、邮箱、所属辅导员（下拉）

---

#### 3.2.3 企业管理

**表格字段**：企业名称 / 行业 / 规模 / 联系方式 / 注册时间 / 审核状态 / 操作（审核通过 / 拒绝 / 查看详情）

**审核状态**用 `el-tag` 区分颜色：
- 待审核：warning（橙）
- 已通过：success（绿）
- 已拒绝：danger（红）

---

#### 3.2.4 岗位审核

**表格字段**：岗位名称 / 发布企业 / 城市 / 薪资范围 / 发布时间 / 审核状态 / 操作（通过 / 拒绝 / 查看详情）

**详情弹窗**：展示完整岗位描述、要求，底部有通过/拒绝按钮。

---

#### 3.2.5 就业统计

**顶部筛选**：年份 + 院系（下拉）

**统计卡片（一行 4 个）**：毕业生总数 / 已就业人数 / 就业率 / 平均薪资

**图表（两列）**：
- 左：柱状图——各院系就业人数对比
- 右：折线图——近12个月岗位投递量趋势

---

#### 3.2.6 数据字典

**表格字段**：字典类型 / 字典键 / 字典值 / 描述 / 操作（编辑 / 删除）

支持按类型分组展示（`el-tabs` 切换不同 dict_type）。

---

### 3.3 辅导员页面

#### 3.3.1 首页 Dashboard

**统计卡片（一行 3 个）**：我的学生总数 / 已就业学生数 / 本月发布指导帖数

**我的学生就业状态**：横向进度条或饼图

**最新动态列表**：学生最近的投递记录（学生姓名 / 投递岗位 / 企业 / 时间）

---

#### 3.3.2 我的学生

**表格字段**：学号 / 姓名 / 专业 / 就业意向 / 投递数量 / 就业状态 / 操作（查看简历 / 查看投递记录）

**就业状态**用 `el-tag`：求职中（蓝）/ 已就业（绿）/ 未开始（灰）

---

#### 3.3.3 指导帖子

**卡片列表**（非表格，每行 3 个卡片）：

每张卡片显示：标题 / 发布时间 / 摘要（前 60 字） / 查看详情按钮

**新增帖子**按钮 → 弹出对话框，含：标题输入框 + 富文本编辑区（可用 `el-input type=textarea` 替代）

---

#### 3.3.4 公开课管理

**表格字段**：课程名称 / 开课时间 / 报名人数 / 上限人数 / 状态 / 操作（编辑 / 删除 / 查看报名名单）

**新增公开课弹窗**：课程名称 / 介绍 / 开课时间（日期时间选择器）/ 报名人数上限

---

### 3.4 学生页面

#### 3.4.1 首页

**欢迎语**：「Hi，[姓名]，今天也要加油求职哦 💪」

**快捷入口卡片（一行 4 个）**：完善简历 / 查看推荐岗位 / 我的投递 / 就业指导

**推荐岗位预览**：横向滚动卡片，展示 5 个推荐岗位，每张卡片显示：岗位名称 / 企业名 / 城市 / 薪资 / 投递按钮

---

#### 3.4.2 我的简历

**整体样式**：类似简历预览器，左侧是可编辑表单，右侧是实时预览（可选，也可只做编辑表单）

**表单分区**：
- 基本信息：头像 / 姓名 / 联系方式 / 邮箱 / 求职意向 / 意向城市
- 教育背景：学校 / 院系 / 专业 / 学历 / 在读时间（可多条）
- 工作/实习经历（可多条）
- 技能标签：`el-tag` 形式，可添加删除
- 自我评价：`el-input type=textarea`

**底部**：保存按钮 + 「AI 优化简历」按钮（点击弹出 AI 对话框）

---

#### 3.4.3 岗位推荐

**顶部说明**：「以下岗位根据您的简历与求职意向为您智能推荐」

**岗位卡片列表**（每行 3 个）：

每张卡片：
- 岗位名称（粗体）
- 企业名 + 城市
- 薪资范围（主色标注）
- 技能标签（`el-tag` 小号）
- 推荐理由（一句话，灰色小字）
- 底部按钮：查看详情 / 立即投递

**右侧悬浮**：AI 对话入口按钮（「问问 AI」），点击展开对话抽屉（`el-drawer`）

---

#### 3.4.4 岗位搜索

**搜索栏**：关键词 + 城市 + 薪资范围（滑块或下拉）+ 行业（下拉）

**结果列表**：同推荐卡片样式，无推荐理由，改为「发布时间」

---

#### 3.4.5 应聘记录

**表格字段**：岗位名称 / 企业 / 投递时间 / 当前状态 / 面试时间 / 操作（查看详情 / 确认面试 / 拒绝面试）

**状态** `el-tag`：
- 待查看：info（灰）
- 已查看：warning（橙）
- 面试邀请：primary（蓝）
- 已录用：success（绿）
- 已拒绝：danger（红）

---

#### 3.4.6 就业指导 - 指导帖子

**卡片列表**（每行 3 个）：标题 / 辅导员姓名 / 发布时间 / 摘要 / 查看全文

点击「查看全文」跳转到帖子详情页（全宽文章样式）

---

#### 3.4.7 就业指导 - 公开课

**表格字段**：课程名称 / 辅导员 / 开课时间 / 剩余名额 / 状态 / 操作（报名 / 取消报名）

---

#### 3.4.8 交流中心

**左侧**：帖子列表（标题 / 发布者 / 发布时间 / 回复数）

**右侧**：帖子详情 + 回复列表 + 回复输入框

**顶部**：发布新帖子按钮

---

### 3.5 企业页面

#### 3.5.1 首页 Dashboard

**统计卡片（一行 3 个）**：发布岗位数 / 收到简历数 / 待处理邀请数

**最新投递列表**：学生姓名 / 投递岗位 / 投递时间 / 操作（查看简历）

---

#### 3.5.2 岗位管理

**表格字段**：岗位名称 / 城市 / 薪资范围 / 发布时间 / 审核状态 / 操作（编辑 / 下线 / 删除）

**新增岗位弹窗（宽 700px）**：
- 岗位名称 / 工作城市 / 薪资下限-上限 / 学历要求（下拉）
- 技能要求（标签输入）
- 岗位描述（`el-input textarea`，行数 6）
- 岗位类型（全职/实习，`el-radio`）

---

#### 3.5.3 求职者推荐

**布局**：同学生端岗位推荐，卡片展示求职者

每张卡片：头像（默认头像）/ 姓名（脱敏，显示姓+**）/ 专业 / 技能标签 / 求职意向 / 按钮：查看简历 / 发送面试邀请

**右侧**：AI 筛选入口（输入要求，AI 推荐合适求职者）

---

#### 3.5.4 应聘管理

**按岗位分 Tab**（`el-tabs`），每个 Tab 是一张表格

**表格字段**：学生姓名 / 专业 / 投递时间 / 简历 / 当前状态 / 操作（查看简历 / 邀请面试 / 拒绝）

## 四、公共组件说明

| 组件 | 说明 |
|------|------|
| `<SideBar>` | 根据角色动态渲染菜单，使用 `el-menu` |
| `<TopBar>` | 显示系统名、当前用户名、退出登录 |
| `<StatCard>` | 统计卡片，props: title / value / icon / color |
| `<JobCard>` | 岗位卡片，props: job 对象 |
| `<AiDrawer>` | AI 对话抽屉，`el-drawer` + 对话气泡 |
| `<StatusTag>` | 状态标签，根据 status 值自动映射颜色 |

## 六、Claude Code 使用提示

1. 先生成公共布局组件 `Layout.vue`（包含 SideBar + TopBar + router-view）
2. 根据角色 token 中的 role 字段动态渲染不同的侧边栏菜单
3. 页面骨架优先用 `el-skeleton` 占位，数据加载完后替换
4. 表格操作列固定在右侧：`:fixed="right"`
5. 弹窗表单统一用 `el-form` + `el-form-item`，配置 rules 做前端校验
